# PRD：事件分析序号 / 金额聚合 / 看板与壳层 UX

> phase: clklog-analytics-ux-polish-v1
> 帽子：产品（`docs/product/`）
> 下游：`docs/architecture/clklog-analytics-design-ux-polish-v1.md`

---

## 1. 阶段目标与范围

修五件用户已指出的问题：公式后的指标序号重复；事件分析无法对声明为 string 的金额做总和；看板卡片灰白双色且默认露出类型标签；自定义 SQL「展开/收起」两个按钮和整页几像素滚动条；Harness 右侧留白。

| 模块 | 本次做什么 |
|------|------------|
| 事件分析指标 | 公式与事件指标共用一套从 1 起的步骤序号，增删后不重复 |
| 事件分析聚合 | string 金额属性可选总和/均值等数值方法，查询按数字解析 |
| 看板卡片 | 标题与内容同一白底；类型标签默认隐藏，看板设置可打开 |
| 自定义 SQL | 「展开结果 / 收起结果」合成一个切换按钮 |
| 壳层 | 去掉最外层几乎滚不动的滚动条；停靠 Harness 贴视口右缘 |

## 2. 验收标准

- [ ] **UX-1**：指标顺序为事件、事件、公式、事件时，序号为 1、2、3、4，不再出现两个「3」。
- [ ] **UX-2**：`pay_amount` 等 `data_type=string` 的事件属性可选「总和」；查询生成数值聚合且不再 400「类型不支持该方法」。非数字串按 0 计入。
- [ ] **UX-3**：看板卡片标题栏与内容区同为白底，标题与图表之间无分界线；新看板默认不显示「事件分析 / 自定义 SQL」等类型标签；看板设置有开关，打开后显示。
- [ ] **UX-4**：SQL 结果工具条只留一个展开/收起按钮，文案随状态切换。
- [ ] **UX-5**：登录后内容区**不绘制**最外层纵向滚动条（含看板页右侧那条）；滚轮仍可滚动长列表与看板格子。停靠 Harness 顶/右/底贴边。
- [ ] **UX-6**：棘轮通过。

## 3. 非目标

- 不把 `pay_amount` 元数据改成 number（不走改字典）。
- 不做显式 DSL `cast` 字段。
- 不改漏斗/留存计算方法校验。
- 不做 VS/上期对比、日期补全轴。
- 不改 Harness 插件源码；不绕过项目绑定、时间窗、LIMIT、超时、只读守卫。
