# 前端视觉资产清单与风格定义（ClkLog 分析平台）

> phase: clklog-analytics-visual-assets-v1
> 版本：v1.0（2026-09-11）
> 上游：`PRODUCT.md`（品牌性格与设计原则）、`docs/product/wireframes-clklog-analytics-v1.md`
> 本文档回答：哪些位置需要视觉资产、长什么样、规格是什么、按什么顺序做。

---

## 0. 门禁要素

- **phase**：`clklog-analytics-visual-assets-v1`
- **阶段目标与范围**：为分析平台前端补齐视觉资产——先落地 P0 批次（A1 主 Logo、A2 Favicon、B1 登录页品牌区、E1 看板空状态、E2 分析无数据空状态），建立"数据感"风格基线（色板 + SVG 图形语言），并沉淀可复用的 `BrandLogo` / `EmptyState` 组件。
- **验收标准**：见 §6。
- **非目标（本 phase 不做）**：
  - 不做 P1/P2 批次（实体类型 icon 体系 D、SQL/元事件/分群空状态 E3–E5、AI 标识 C3/G1、登录背景 B2、错误页 F1/F2 等），列入后续 phase。
  - 不引入任何位图资源（favicon 除外）；不引入新 npm 依赖。
  - 不改动布局结构、路由与既有组件交互逻辑，仅替换/增强视觉呈现。
  - 不改变 antd 主题 token 与全局组件外观，视觉资产自带色板常量。
  - 不生成"插画式"装饰图；空状态与 Logo 均为线性几何 SVG，遵守 PRODUCT.md Anti-references。

## 1. 背景与约束

前端现状（2026-09-11 代码核查）：

- **零图片资产**：全前端无 png/jpg/svg/ico 文件；`index.html` 无 favicon。
- **icon 已部分具备**：侧边栏顶级菜单已配 `@ant-design/icons`（报表/分析/用户/埋点管理/项目权限/运维/设置/退出）；子菜单项为纯文本（B 端惯例可接受）。
- **品牌区为纯文字**：侧边栏品牌行折叠后仅单字母 C；登录页为灰底 + Card，无品牌视觉。
- **空状态用 antd 默认**：`Empty` 组件默认插画 + "暂无数据"式文案，无行动引导。

**硬约束（来自 PRODUCT.md，不得违反）**：

- 品牌性格：**专业、克制、可信**。
- Anti-references：不用高饱和装饰、大面积渐变、无意义动效；不引入消费级插画风格。
- 设计原则：分析任务优先、专家效率、证据先于推断。
- 技术约束：全部视觉资产用 **SVG**（内联 React 组件或 `assets/` 文件），不引入位图大图；图标复用 `@ant-design/icons`，不重复造轮子。

## 2. 风格定义：数据感（Data Sense）

"数据感"不是把界面画成科技海报，而是**用数据可视化的图形语言做克制的视觉隐喻**。具体量化定义：

| 维度 | 定义 |
|---|---|
| 主色 | 延续 antd 品牌蓝 `#1677FF`；深色文字 `#1F2329`；次级文字 `#646A73`；边框 `#E5E6EB` |
| 强调色 | 单一强调色 `#1677FF`，只用在插画的高亮趋势线与端点（算一个整体元素）；不做多色混搭 |
| 图形语言 | 线性描边（1.5–2px）、圆角 2–4px、几何图形（折线/柱状/圆环/散点/网格/坐标系） |
| 隐喻素材 | 空坐标系、待填充的柱状、虚线折线、数据点、网格背景——表达"数据待产生/可填充" |
| 禁用 | 3D 渲染、写实纹理、大面积渐变、卡通角色、高饱和撞色、发光特效 |

**一句话**：像一个"数据尚未填充时的分析画布"——干净、留白、一眼看懂是数据分析产品。

## 3. 资产清单（按位置分组）

### A. 全局品牌资产

| # | 资产 | 位置 | 格式/规格 | 设计要点 | 优先级 |
|---|---|---|---|---|---|
| A1 | 主 Logo（图形标 + 文字标） | 侧边栏品牌区（替换当前单字母 C） | SVG 内联；图形标 24×24，组合标 ≤160×32 | 图形标与"数据上升"隐喻结合（折线/柱状/网格）；文字标"ClkLog 分析平台"或仅"ClkLog" | P0 |
| A2 | Favicon | `index.html` `<link rel="icon">` | 单文件 SVG（32×32 viewBox，随 A1 同源图形标），≤1KB | 与主 Logo 同源；纯色底 + 白标，小尺寸可辨识。**不用 PNG**：旧版 Safari 可能不显示，B 端内部工具可接受（见架构方案 §9） | P0 |
| A3 | 品牌色板常量 | `src/styles/tokens.ts` 或现有主题文件 | CSS 变量 / TS 常量 | 主色/文字/边框/强调色统一收口，供插画与组件复用 | P1 |

### E. 空状态（重点）

空状态是用户最频繁遇到的"失败时刻"，统一用定制 SVG 插画 + 行动引导文案替换 antd 默认 Empty。统一规格：**SVG 240×160，线性描边 1.5–2px，中性灰为主、单强调色点缀，图形为"数据待填充"隐喻**。

| # | 场景 | 位置 | 文案与 CTA | 优先级 |
|---|---|---|---|---|
| E1 | 看板为空 | 看板列表/工作室 | "还没有看板，创建第一个看板 →"（按钮跳创建） | P0 |
| E2 | 分析无数据 | 事件分析/漏斗/留存结果区 | "当前时间范围内暂无数据" + 调整时间范围引导 | P0 |
| E2b | 分析未查询引导 | 事件分析/漏斗/留存结果区（刚打开未点查询） | 中间插画 + "在左侧配置…后点击"查询"查看结果"（无主标题行） | P1 |
| E3 | SQL 无结果 | SQL 编辑器结果区 | "查询无结果，检查条件或时间范围" | P1 |
| E4 | 埋点尚未上报 | 元事件列表 | "尚未发现上报事件，接入 SDK 后自动发现" + 文档链接 | P1 |
| E5 | 分群/标签为空 | 分群/标签列表 | "还没有分群，创建第一个用户分群 →" | P1 |
| E6 | 搜索无匹配 | 字典/列表搜索 | "无匹配结果，尝试其他关键词" | P2 |

**实现方式**：新建 `src/components/EmptyState.tsx`（封装 antd `Empty` + 定制 `image` prop + CTA 插槽），`<EmptyState variant="dashboard" onAction={...} />`。

## 4. 实施顺序

| 批次 | 范围 | 预估工作量 | 收益 |
|---|---|---|---|
| **P0（本周）** | A1 Logo + A2 Favicon + B1 登录品牌区 + E1/E2 空状态 | 中 | 品牌存在感 + 最高频空状态体验 |
| **P1（两周内）** | D 实体 icon 体系 + E3/E4/E5 + C3/G1 AI 标识 + A3 色板收口 | 中 | 列表页认知负担显著下降 |
| **P2（随迭代）** | B2 登录背景 + F1/F2 错误页 + C1/C2 + F3 骨架屏 | 低 | 收尾打磨 |

## 5. 落地路径建议

```
apps/analytics-web/src/
├── assets/
│   ├── logo/               # logo.svg、logo-mark.svg、favicon.png
│   └── illustrations/      # empty-dashboard.svg、empty-analysis.svg、error-403.svg ...
├── components/
│   ├── BrandLogo.tsx       # 品牌标（组合标/图形标两种尺寸）
│   ├── EmptyState.tsx      # 空状态封装（variant → SVG + 文案 + CTA）
│   └── EntityIcon.tsx      # 实体类型 icon 分发
└── styles/
    └── tokens.ts           # 色板/尺寸常量（A3）
```

规则：

- **SVG 全部内联或本地 assets**，不引入 CDN 图片资源；favicon 同为 SVG（不做 PNG 兜底）。
- 插画 SVG 保持"单强调色 + 中性灰"，实现时直接套用 A3 色板常量，禁止硬编码色值。
- 新资产必须跟随本清单登记；改动视觉规范时更新本文档而非另起文件。

## 6. 验收标准

- [ ] A1/A2：品牌区与浏览器标签出现统一 Logo；favicon ≤10KB 且 16px 可辨识。
- [ ] B1：登录页出现品牌组合标，替换纯文字标题。
- [ ] D：实体类型 icon 在元事件/字典/分群列表可读，`EntityIcon` 单一分发。
- [ ] E1/E2：看板与分析空状态为定制插画 + 行动引导，非 antd 默认图。
- [ ] 无新增位图资源（除 favicon），全量视觉资产通过 A3 色板引用。
- [ ] 视觉资产不违反 PRODUCT.md Anti-references（无高饱和/大面积渐变/无意义动效）。
