## 1. 阶段目标与范围

把运营「核心数据日报」（活跃用户 / 新用户 / 充值 / 次留…Dn）落成**可保存卡片**；优先事件分析与留存分析，漏斗不做，自定义 SQL 本期不做合成宽表。同时修事件分析「添加公式」在 280px 配置轨里的截断，并为事件/留存/SQL 相关图形补 Grafana 风格的显示值（最新 / 平均 / 最大 / 最小 / 最早 / 合计）。

| 模块 | 本次做什么 |
|------|------------|
| 核心数据卡片 | 拆成两张：事件卡（日历指标）+ 留存卡（队列 Dn）；不能合成一张宽表 |
| 公式编辑器 | 左/运算/右/格式纵向排布，别名完整可见 |
| 事件分析图形 | 折线、趋势、柱状、堆积、累计、分布、饼图、数值 |
| 留存分析图形 | 第 N 日趋势（横轴队列日）；不做每日趋势 |
| 显示值 | 柱状/饼/数值可勾选；折线与留存趋势不叠显示值 |

## 2. 验收标准

- [ ] **EC-1**：事件分析一张查询可同时出 DAU（任意/启动事件·触发用户数）、DNU（同上且 `is_first_day=1`）、充值（充值事件·金额总和）；公式如 DOU=DAU÷DNU 在窄栏不截成 `DAI`/`DN`/`—`。
- [ ] **EC-2**：上述事件结果可保存为事件卡片；图表类型含折线/趋势/柱状/堆积/累计/分布/饼图/数值/表格，重开与看板复现同一类型。
- [ ] **EC-3**：留存分析按日、默认 n_list 为 D1/D2/D3/D7（D15 可选）；第 N 日趋势：X=队列日、系列=各 N 留存率。不做每日趋势。
- [ ] **EC-4**：漏斗与自定义 SQL 不承担这张核心宽表；不新增「日历指标 JOIN 队列留存」的 SQL 模板。
- [ ] **EC-5**：公式槽纵向：左操作数、运算符、右操作数、格式各占一行；运算符与格式下拉完整显示 `＋－×÷` / `数字|百分比|两位小数|三位小数`。
- [ ] **EC-6**：事件分析「图表类型」可选：折线、趋势、柱状、堆积、累计、分布、饼图、数值。无分组时数值卡可用；饼图/分布在类别过多时 Top8 +「其他」，不静默丢点。
- [ ] **EC-7**：留存结果图仅为第 N 日趋势；旧卡 `chart_type=trend|line|daily_trend` 打开后落到第 N 日趋势。
- [ ] **EC-8**：折线 / 趋势 / 第 N 日趋势只画线+图例，不叠显示值、平均虚线或预测。柱状/堆积/饼/数值仍可勾选显示值。
- [ ] **EC-9**：SQL 柱/饼/数值的字段设置可勾选显示值；折线/趋势不叠。配置写入 `chart_config.options.stat_calcs`，非法键拒绝保存。
- [ ] **EC-10**：单测覆盖公式纵向文案、事件图类型解析、留存未到期为 null、统计归约。棘轮通过。
- [ ] **EC-11**：按日分组的事件结果按时间升序；步骤序号与别名同一行。
- [ ] **EC-12**：卡片库「核心数据 · 留存」为 `$AppStart` 首日新用户，n=1,2,3,7，第 N 日趋势。
- [ ] **EC-13**：留存结果拆两张表（人数 / 留存率）；`入组日+N > 今天（Asia/Shanghai）` 显示 `-`，不是 0。


## 3. 非目标

- 不把日历 DAU 与队列 Dn 合成一张查询或一张卡片。
- 不做漏斗时间分桶、不做分布分析模型（次数/天数分布），分布图只是当前结果的构成图。
- 不把预测接到留存第 N 日趋势。
- 不改 ClickHouse 查询语义、不放宽 10 条指标上限。
- 不把日历 DAU 与队列 Dn 合成一张查询。卡片库落两张命名卡（事件名取本项目 `$AppStart` / `order_pay_success`），不自动塞进某个看板。

## 4. 核心数据如何拆卡

| 卡片 | 分析 | 指标 | 图形建议 |
|------|------|------|----------|
| 核心数据 · 日历 | 事件分析 | DAU、DNU、充值；可选公式 | 表格 + 折线/趋势 |
| 核心数据 · 留存 | 留存分析 | 首日新用户、回访=活跃，n=1,2,3,7 | 第 N 日趋势 + 人数表/留存率表 |

充值事件名以项目元数据为准，产品不写死。

## 5. 图形与显示值

| 图形 | 语义 | 允许的显示值 | 默认 |
|------|------|--------------|------|
| 折线 | 各类目点连线 | （不显示） | 无线下统计 |
| 趋势 | 时间走向（可连空） | （不显示） | 无线下统计 |
| 第 N 日趋势 | 队列日 × 各 N 率 | （不显示） | 无线下统计 |
| 柱状 | 类目对比 | 平均/最大/最小/最新/合计 | 平均、最大 |
| 堆积 | 多指标或构成堆叠 | 同柱状 | 平均、最大 |
| 累计 | 沿 X 轴累加 | （不显示） | 无线下统计 |
| 分布 | 单指标构成（柱，百分比） | 平均/最大/最小 | 平均、最大 |
| 饼图 | 单指标扇区 | 合计、最大 | 合计 |
| 数值 | 跨行归约成指标卡 | 全部六项 | **最新**（禁止沿用「按日求和」） |

「合计」对去重人数、留存率无业务含义，默认不勾；用户仍可勾选并自行解读。
