## 1. 阶段目标与范围

自定义 SQL 顶栏目前只有日历起止日，默认看起来像「7 天」，但分不清是**写死的那 7 天**还是**滚动最近 7 天**。事件 / 漏斗 / 留存工具条虽有「今天 / 近 7 天」等快捷项，却用解析后的日期反推预设：过了零点「近 7 天」会变成一段冻住的静态窗。

本期把时间范围做成与**数数**同口径：触发器显示语义名称（如「过去7天」），面板可在**动态时间**与**静态时间**之间切换；查询、存卡片、看板刷新都按同一套规则在执行时再解析。

| 模块 | 本次做什么 |
|------|------------|
| 自定义 SQL | 用同一套时间面板替换 `RangePicker`；默认「过去7天」；最大 90 天不变 |
| 事件 / 漏斗 / 留存 | 工具条换成同一套面板，补齐过去 vs 最近、上周/本周、自某日、自定义动态偏移 |
| 卡片与刷新 | DSL 持久化 `relative`；无 `relative` 的旧卡片保持静态；有 `relative` 的卡片每次查询按上海日历重算起止日 |
| 触发器文案 | 动态范围显示预设名；静态范围显示 `YYYY/MM/DD → YYYY/MM/DD` |

## 2. 用户流程

1. 打开任意分析页或自定义 SQL，默认选中 **过去7天**（不含今天）。触发器写「过去7天」，不写死一段日期让人猜。
2. 点击触发器：左侧选预设（昨日/今日、上周/本周、上月/本月、过去7/最近7、过去30/最近30、自某日至昨日/至今、自定义时间）；右侧 **动态时间 / 静态时间**；动态可填「N 天前 → M 天前」；静态用两个日历点起止日。标题展示本次解析出的日期。
3. 点「应用」后查询使用解析后的 `start/end`。保存卡片时连同 `relative` 一起存。次日打开或看板刷新时，动态范围跟着日历滚，静态范围不变。
4. 旧卡片只有起止日、没有 `relative`：继续按保存时的日期查，行为与现在一致。

## 3. 口径（与数数对齐）

日历日以 **Asia/Shanghai** 为准。偏移 0 = 今天，1 = 昨天。

| 预设 | 含义 | 动态偏移 |
|------|------|----------|
| 今日 | 今天 | 0 → 0 |
| 昨日 | 昨天 | 1 → 1 |
| 过去 N 天 | N 个**完整自然日**，结束于昨天 | N → 1 |
| 最近 N 天 | 含今天共 N 个自然日 | N-1 → 0 |
| 本周 | 本周一（中国）→ 今天 | — |
| 上周 | 上周一 → 上周日 | — |
| 本月 | 本月 1 日 → 今天 | — |
| 上月 | 上月 1 日 → 上月最后一天 | — |
| 自某日至昨日 / 至今 | 锚点开始日固定，结束日动态 | — |
| 自定义动态 | 两个「天前」整数 | from → to（from ≥ to） |
| 静态 / 自定义时间 | 日历起止日，不再滚动 | 无 `relative` |

今日为 2026-09-11 时：**过去7天** = 2026-09-04 → 2026-09-10；**最近7天** = 2026-09-05 → 2026-09-11。

## 4. 验收标准

- [ ] **SC-1**：新开自定义 SQL、事件、漏斗、留存，默认触发器为「过去7天」；执行注入的日期不含今天，含昨天往前 7 个完整自然日。
- [ ] **SC-2**：选「最近7天」后触发器为「最近7天」，执行窗含今天；与「过去7天」在同一天解析出的 `start/end` 不同。
- [ ] **SC-3**：静态时间（日历或「自定义时间」）触发器显示具体日期，DSL 无 `relative`；次日查询起止日不变。
- [ ] **SC-4**：动态范围保存到卡片后，看板/目录刷新与再次打开分析页按当天上海日历重算；旧卡片无 `relative` 不重算。
- [ ] **SC-5**：自定义 SQL 解析后的含首尾跨度超过 90 天时拒绝执行，提示最大 90 天；分析查询保持既有分钟粒度 1 天上限。
- [ ] **SC-6**：面板含昨日/今日、上周/本周、上月/本月、过去/最近 7 与 30、自某日至昨日/至今、自定义动态偏移；应用前可取消，不改当前查询。
- [ ] **SC-7**：相关自动测试与 `python3 scripts/arch_ratchet.py` 通过。

## 5. 非目标

- 不做 VS / 上期 / 去年同期时间对比（DSL 里 `compare` 仍保留，UI 不做）。
- 不改时间粒度（分钟/季/年）、不改 SQL 注入方式（仍只把解析后的日期交给既有守卫）。
- 不改 ClickHouse 表、不放宽 SQL 只读/LIMIT/超时。
- 不为时间范围单独加 Harness 工具；页面快照里的 `time_range` 随 DSL 带上 `relative` 即可。
