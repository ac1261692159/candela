## 1. 背景与问题

当前看板是 Ant `Row/Col` 流式网格，卡片宽度只能按 12 栅格粗分，不能拖、不能改高、不能加列。列表和卡片标题栏都挂着删除/叉号，误触成本高。打开看板会对每张卡打 ClickHouse，同一张卡挂在多块看板会重复计算。自定义 SQL 左侧事件/属性列表离左缘还有一截空白。

对标：Grafana 看板（排布、列数、面板菜单、自动刷新）；数数标签说明卡（自定义文字色与背景色）。**不做 Grafana 变量筛选。**

---

## 2. 用户与场景

| 角色 | 场景 |
|------|------|
| 分析师 | 打开「充值」看板立刻看到上次结果，过期卡在后台刷新；把趋势图拉高、把两张卡并排；加一张黄色说明写口径 |
| 运营 | 看板列表只点名称进入；不会在列表误删整块看板 |
| 看看板的人 | 卡片没有常驻叉号；要挪走某张卡走面板菜单「从看板移除」 |

---

## 3. 产品裁决（已锁定）

1. **排布完全复制 Grafana 的网格语义**（不是视觉皮肤）：默认 24 列、可拖、可缩放、垂直紧凑、右下角缩放柄。列数可在看板设置里改为 12 / 16 / 24。
2. **不做 Grafana 变量 / 模板变量 / 顶部筛选条。**
3. **缓存按卡片独立存储**（一张卡可被多块看板引用）。打开看板先渲染缓存；该看板的「缓存超时」决定这张卡在本页是否过期。后台线程按引用该卡的看板中**最短 TTL** 温热缓存。
4. **删除不出现在列表 chrome**：看板删除只在看板齿轮设置里；从看板移除只在面板菜单；删除卡片资产只在对应编辑页（SQL 页 / 事件·漏斗结果区 / 标签卡编辑）。
5. **标签卡**是库内一等卡片 `type=text`，不查 ClickHouse、不进缓存、不走 refresh。
6. **旧 12 列布局只读时放大到 24 列**（x、w ×2），用户拖过一次后按 24 列坐标落库，不再二次放大。
7. SQL 字典列表贴左：去掉 Tree 占位箭头与多余 content padding，事件名从分组内容区左缘起排。

## 6. 缓存与刷新（体验）

打开看板：

1. 首屏画出每张卡的缓存结果（或空骨架）。标签卡直接画 DSL，不等待。
2. 留存卡仍提示「暂不支持在看板刷新」，不打查询。
3. 查询卡（sql / event / funnel）：有缓存且未过期 → 不请求。无缓存或已过期 → 排队刷新（同页并发 2）。
4. 手动点面板「刷新」→ 强制重算并写缓存。
5. 自动刷新到达间隔 → 本页所有查询卡强制重算。

后台：进程内定时扫描「至少被一块看板引用」的查询卡；缓存年龄超过引用看板最短 TTL 则重算写入。标签卡、留存卡、未挂看板的卡跳过。崩溃恢复：下一次 tick 继续，不要求恰好一次。

缓存过大（>512KB）时存截断标记，前端提示「缓存过大，已截断」，可手动刷新。

## 7. 标签说明卡

- 创建：看板「添加」→「标签说明」，或卡片库（较少用）。
- 字段：标题（卡片名）、正文、文字颜色、背景颜色；可选字号 12/14/16/18。
- 展示：整块面板铺满背景色，正文换行，不跑查询。
- 编辑：面板菜单「编辑」打开同一弹层；弹层内可删这张库卡片（从所有看板摘掉）。
- 从看板移除：只摘引用，不删库卡片。

## 8. 验收标准

- [ ] **DS-1** 看板列表无删除按钮；删除只在看板齿轮里，二次确认后列表不再出现该看板，卡片库仍在。
- [ ] **DS-2** 看板内卡片无常驻叉号；「从看板移除」仅面板菜单，确认后卡还在卡片库。
- [ ] **DS-3** 卡片库列表无删除列；SQL 页在已绑定卡片时可删；事件/漏斗结果区在 `?card=` 时可删；标签卡在编辑弹层可删。
- [ ] **DS-4** 看板可拖拽、缩放、垂直紧凑，松手后刷新仍保持位置；默认 24 列。设置改列数后块按比例变窄/变宽。
- [ ] **DS-5** 旧看板（历史 width 按 12 列存）打开时视觉上铺满约一半/全宽，不会缩在左上角一小条。
- [ ] **DS-6** 可添加标签卡，文字色与背景色自定义并保存复现。
- [ ] **DS-7** 打开看板先出现缓存（若有）；TTL 内不打 ClickHouse；TTL 外该卡刷新；同一 card_id 在两块看板共享一份缓存。
- [ ] **DS-8** 看板自动刷新按设置间隔强制刷新查询卡；关闭则不自动打。
- [ ] **DS-9** 服务进程内有卡片缓存刷新循环，跳过 text/retention/未引用卡；进程退出时循环停止。
- [ ] **DS-10** 自定义 SQL 字典事件/属性文本贴分组内容左缘，不再出现大段左白。
- [ ] **DS-11** `python3 scripts/arch_ratchet.py` 通过；查询仍强制 `project_name` + 时间范围 + LIMIT/超时；不改社区版表。

## 10. 文案

| 位置 | 文案 |
|------|------|
| 齿轮 | 看板设置 |
| 自动刷新 | 关闭看板后定时器停止。打开期间按间隔重算本页图表。 |
| 缓存超时 | 打开看板时，卡片结果超过此时长会在后台重算。同一张卡被多块看板引用时共用一份缓存。 |
| 从看板移除 | 卡片仍留在卡片库，可再次添加。 |
| 删除看板 | 只删除这块看板，卡片仍留在卡片库。 |
| 删除卡片 | 所有看板中的引用会一并去掉，不可恢复。 |
| 空看板 | 还没有卡片。点「添加卡片」从卡片库选已有分析，或加一张标签说明。 |
