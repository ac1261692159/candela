# PRD：漏斗步骤插入排序与结果表两行

> phase: clklog-analytics-funnel-edit-table-v1

> 下游：`docs/architecture/clklog-analytics-design-funnel-edit-table-v1.md`

---

## 1. 阶段目标与范围

漏斗配置轨：把底部「添加步骤」收进每一步卡片，同一行两个动作（插入 / 添加），并支持调整已有步骤顺序。

结果表：表头只用步骤名，不再拼「人数」。表体固定两行：第一行数值，第二行当前齿轮所选的转化率或流失率。

## 2. 验收标准

- [ ] FT-1：每一步卡片底部同一行两个按钮：「插入步骤」「添加步骤」。配置轨底部不再有整行「添加步骤」。按钮内文字横向书写、不竖排。
- [ ] FT-2：插入步骤 = 在当前步之前插入空白步；添加步骤 = 在当前步之后插入空白步。达到 32 步时两钮不可用并提示上限。至少 2 步规则不变。
- [ ] FT-3：每一步可上移 / 下移；第一步上移不可用，最后一步下移不可用。移动只改顺序，不改写用户已起的步骤名。
- [ ] FT-4：结果表（分析页与看板 `chart_type=table` 漏斗卡）列头为步骤名，不含「人数」。第一行「数值」，第二行「转化率」或「流失率」（随齿轮）。第一步转化 100%、流失 0%；其后相对上一步。分组时每个分组各两行。
- [ ] FT-5：查询返回的步骤列 title 不再追加「人数」。旧缓存带「人数」后缀时前端仍剥掉再展示。
- [ ] FT-6：单测：插入/添加/上移下移；表模型两行且无「人数」；切流失率改第二行文案。

## 3. 非目标

- 不改 windowFunnel SQL、2～32 步上限、窗口期、分组。
- 不做拖拽排序（本期按钮移动即可）。
- 不改自定义 SQL 图表漏斗。
- 不把点击漏斗图的切片写进表格。

## 4. 体验

- 插入 / 添加是虚线次要按钮，等分一行，标签 nowrap。
- 上移 / 下移 / 删除放在步骤标题右侧，图标按钮，有 aria-label。
- 比率行与图上「相对第一步」无关：表用逐步相对上一步，与齿轮转化/流失开关一致。
