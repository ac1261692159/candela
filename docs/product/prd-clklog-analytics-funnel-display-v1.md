# PRD：漏斗结果横纵布局与阈值配色

> phase: clklog-analytics-funnel-display-v1
> 上游：`prd-clklog-analytics-result-settings-v1.md`、`prd-clklog-analytics-funnel-steps-v1.md`
> 下游：`docs/architecture/clklog-analytics-design-funnel-display-v1.md`

---

## 1. 阶段目标与范围

长漏斗（如 24 步新手引导）不再用彩虹色、标签写在条带内部的 ECharts 漏斗图。结果齿轮增加**横向 / 纵向**，条带用默认色 + 按「相对上一步」转化分档变色。图上标注的比率是**相对第一步**；悬停仍是相对上一步。

## 2. 验收标准

- [ ] FD-1：齿轮内可切「横向 / 纵向」。未保存的新漏斗分析在**计算完成后**：步数 &lt; 10 默认横向，步数 ≥ 10 默认纵向。用户手动选择后不再被步数覆盖。已写入 `_view.funnel_layout` 的卡片按保存值，不被步数改写。
- [ ] FD-2：横向：ECharts **梯形漏斗**（`type: 'funnel'`，居中收窄）。左侧 `{序号} {标题}` 左对齐，相对第一步转化/流失右对齐（第一步转化 100% / 流失 0%）。行宽取最长一行「序号 标题 + 约 4px + 比率」，其余行中间留白补齐。标题不画在漏斗块上。块宽 = 该步人数。
- [ ] FD-3：纵向：底部显示序号 + 标题；柱顶显示相对第一步的转化或流失。
- [ ] FD-4：悬停 tooltip 仍为步骤名、人数、相对**上一步**的转化率或流失率（与现网一致）。
- [ ] FD-5：取消彩虹色。设置可选默认色，默认蓝 `#1677ff`。另 3 档按「相对上一步」的转化率给**该步**上色，默认：≥90% 用默认蓝；80%～89% 黄 `#faad14`；50%～79% 红 `#ff4d4f`；&lt;50% 深紫 `#531dab`。百分比与颜色均可调。齿轮比率默认为转化率；切到流失率时分档按 `流失 = 1 - 转化` 换算展示与判定。
- [ ] FD-6：保存 / 覆盖卡片写入 `_view.funnel_layout`、`_view.funnel_color`、`_view.funnel_table_col_chars`（以及已有 `funnel_rate`）。看板 `type=funnel` 卡读同一套 `_view`。缺 `funnel_layout` 的旧卡：按步数套用 FD-1 默认（未手选过）。
- [ ] FD-7：单测覆盖默认方向、相对第一步标注、分档颜色、tooltip 仍用上一步、列宽下限 6。
- [ ] FD-8：结果表每列最少 6 个汉字宽，表头/单元格 nowrap（禁止竖字）；齿轮可设默认列宽（字符数，下限 6）；列多时横向滚动。
- [ ] FD-9：点击某一步的漏斗块 / 柱：以前端已有人数把该步当作 100% 向后重算；该步之前的图形与百分比不显示；漏斗 `max` 改用该步人数以便后续步条足够长。点击图空白处还原为从第一步起算。不请求后端。不写入 `_view`。

## 3. 非目标

- 不改漏斗 SQL、人数口径、2～32 步上限。
- 不改自定义 SQL 图表漏斗（仍 3～8 列）。
- 不做看板卡上的现场改设置。
- 不把漏斗拆成多段里程碑查询。

## 4. 体验

- 「横向」= 步骤从上到下的居中梯形漏斗，左侧放序号/标题/相对当前基数步比率。
- 某步流失过大时，点该步把后续步放大查看；点空白还原。结果表仍显示全链路，不随点击裁剪。
- 结果表表头横向书写；列宽不够就滚动，不把汉字压成一字一列。
- 设置项标签 nowrap；弹层可滚动。长步骤名单行省略。
- 横向条数多时分析页加高画布；看板卡内可滚动。
