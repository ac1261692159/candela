# PRD：分析指标告警与邮件/短信通道

> phase: clklog-analytics-alerting-v2
> 日期：2026-09-10
> 上游：`docs/product/prd-clklog-analytics-alerting-v1.md`
> 下游：`docs/architecture/clklog-analytics-design-alerting-v2.md`

## 1. 阶段目标与范围

在 V1 运维告警工作台之上增加两类能力：

1. **分析指标告警**：超管选择已保存的分析卡片（事件/漏斗/留存/SQL）及其数值列，用卡片缓存里的最新值做阈值判断。用于 DAU、CDN 下载成功率等业务指标，不另开一条 ClickHouse 查询。
2. **通知通道**：联系人除飞书 webhook 外，可配 **邮件** 与 **短信**（腾讯云 SMS）。未在部署环境配置 SMTP / 短信密钥时，对应类型不可新建。

同期体验修补（同发版，不算独立 phase）：

- 概览列出**当前触发中**的规则，可一键屏蔽。
- 屏蔽除日期范围外，支持快速「N 小时 / N 天」。

## 2. 用户与权限

仍仅平台超管。路径仍为 `/ops/alerts`。

## 3. 分析指标规则

- 可**新建、删除**；内置 6 条运维规则仍不可删。
- 数据来源是卡片缓存最新一行的选定列，**不**在检测周期里重跑事件分析 SQL。
- 缓存失败、过大截断、或超过 30 分钟未刷新：本轮跳过，不把空值当 0 触发。
- 上限 50 条分析规则，防止检测器拖垮。
- 比较符、级别、粒度、持续、重复间隔、恢复通知、联系人与 V1 相同。
- 检测周期页面仍展示「每 60 秒检测」；实际观测值随卡片 worker 刷新（约 30s 起，受 TTL/退避约束）。

## 4. 通知通道

| 类型 | 配置 | 未配置时 |
|---|---|---|
| 飞书 webhook | 超管粘贴机器人 URL（与 V1 同） | 仍可用 |
| 邮件 | 部署环境 SMTP（Host/账号/密码/发件人） | 联系人里不可选邮件 |
| 短信 | 腾讯云 SMS（SecretId/Key、SdkAppId、签名、模板 ID） | 联系人里不可选短信 |

默认联系人仍只能有一个，类型不限。规则未指定联系人时走默认。

短信模板约定一个参数：短文本（规则名 + 当前值 + 阈值）。密钥不进 git、不进日志、不进通知记录。

## 5. 屏蔽

- 概览：未恢复规则表，行内「屏蔽」+ 快捷时长。
- 屏蔽 Tab：快捷时长（1 小时 / 6 小时 / 1 天 / 3 天 / 7 天）或自选起止。
- 屏蔽期内不外发任何通道；页面历史仍记事件。

## 7. 非目标

- 不接企微、电话、钉钉。
- 不做环比昨天/上周、预测线、自动处置。
- 不在检测器里直接执行分析 SQL / 不引入 Prometheus。
- 不接阿里云短信；SMTP 未配时不假装已发送。
- 不修改 Harness 官方 Web 源码（`startTime` 只在代理 shim 里防护）。
