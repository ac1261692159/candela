# PRD：运维告警工作台

> phase: clklog-analytics-alerting-v1
> 日期：2026-09-10
> 上游：`docs/product/prd-clklog-analytics-ops-console-v1.md`（首期仅页面可见 + 单阈值）
> 下游：`docs/architecture/clklog-analytics-design-alerting-v1.md`
> 对标：腾讯云可观测平台 · 告警策略（触发条件 / 分级 / 屏蔽 / 通知 / 联系人）

---

## 1. 阶段目标与范围

把运维「监控告警」从「6 条内置规则 + 一个数字阈值 + 页面列表」升级为可配置的告警工作台：规则语义对齐腾讯云触发条件，通知走飞书自定义机器人，并提供屏蔽、通知记录、概览。

只覆盖**平台运维指标**（现有 6 条内置规则）。分析指标告警（DAU、CDN 下载成功率等）与邮件/短信为 V2。

## 2. 用户与权限

仅平台超管（`platform_role = super_admin`）。菜单仍在「运维 → 监控告警」，路径 `/ops/alerts`。非超管不可见、直访无权限。

## 3. 信息架构

单页工作台，Tab：

| Tab | 内容 |
|---|---|
| 概览 | 今日触发数、未恢复数、通知失败数、Top 规则 |
| 策略 | 6 条内置规则列表；点「编辑条件」打开抽屉 |
| 历史 | firing / resolved 事件，含级别、触发值、持续 |
| 屏蔽 | 按规则或全局、起止时间、原因 |
| 通知记录 | 每次飞书投递成功/失败（不展示完整 webhook） |
| 联系人 | 飞书自定义机器人；可设默认 |

## 4. 规则编辑器（对标腾讯云「修改触发条件」）

每条内置规则可配，**不可新增、不可删除**（沿用 ops-console D6 的「规则集合」约束，放开的是条件字段）：

| 字段 | 选项 / 默认 |
|---|---|
| 级别 | 紧急 / 警告 / 提示，默认警告 |
| 比较关系 | `>` `>=` `<` `<=`（V1 不做环比昨天/上周） |
| 阈值 | 数字；单位随规则展示（%、次、分钟） |
| 数据点统计粒度 | 1 / 5 / 15 分钟 |
| 异常持续 | 连续 M 个粒度（默认 1） |
| 检测周期 | 页面固定展示「每 60 秒检测」 |
| 重复通知间隔 | 触发中默认 60 分钟再打一次飞书 |
| 恢复通知 | 默认开 |
| 联系人 | 可选；空则走默认联系人 |

内置规则默认比较符：磁盘可用% `<`；链路停滞分钟 `>`；CH 连续失败 `>=`；慢查询次数 `>`；失败率 `%` `>`；卡片缓存失败 `>=`。

## 5. 通知

- 渠道 V1：**仅飞书自定义机器人 webhook**。
- 触发时通知一次；持续 firing 按重复间隔再通知；恢复可通知。
- 屏蔽期内不外发，页面历史仍记录事件。
- webhook 只由超管写入；列表只显示脱敏 URL；不进 git、不进日志正文。

## 7. 非目标

- 不接分析卡片/事件分析指标（DAU、CDN 成功率等）——V2。
- 不接邮件、短信、企微、电话。
- 不做环比昨天/上周、预测线告警、自动处置。
- 不引入 Prometheus / Grafana。
- 不开放用户自定义新指标；6 条规则集合仍由版本种子决定。
