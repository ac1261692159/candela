## 1. 阶段目标与范围

事件分析的「分析指标」改成数数同构：一条指标是 **事件 + 可选属性 + 计算方法**，或 **公式（Σ）**。补人均值、任意事件、按类型的布尔/列表算法、阶段汇总、分钟粒度与时长展示。

不改漏斗、留存、SQL 图、看板协议。不做 Session / 间隔 / 分析主体切换。

用户可感知的三刀与架构文档 §1 相同；本期一次做完。

## 2. 验收标准

与架构文档 TD-A1～A7、TD-B1～B5、TD-C1～C4、TD-R1～R3 对应，可核对项：

- [ ] 选择器顺序：事件 → 可选属性 → 计算方法。无属性时只有总次数、触发用户数、人均次数。
- [ ] 文案为「总次数」「触发用户数」。旧卡片 `type=count|uniq_user` 仍能查询。
- [ ] 人均次数不要求属性；人均值 = 属性总和 / 人数，缺属性则 400。
- [ ] 可选「任意事件」，SQL 不写 `event =`，仍有项目与时间过滤。
- [ ] 最多 10 条指标。
- [ ] 数值补 P25/P75/方差/标准差/自定义分位；布尔真假空；列表去重与元素去重。
- [ ] Σ 公式只引用本查询指标做加减乘除，除零显示 `—`。
- [ ] `$event_duration` 的总和/均值/人均值默认按秒显示，结果设置可改纯数字。
- [ ] 时间粒度有「合计」「按分钟」；分钟跨度超过 1 天不可查。
- [ ] 人数类默认阶段汇总为整段去重，不是每日人数相加。
- [ ] Datetime 分组可按时段汇总（小时 0–23、每月几号、分钟 0–59）。
- [ ] 单测覆盖人均值、任意事件、公式除零、旧 DSL、分钟跨度、阶段合计去重。棘轮通过。
