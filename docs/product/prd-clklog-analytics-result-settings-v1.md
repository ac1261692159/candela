# PRD：分析结果设置齿轮

> phase: clklog-analytics-result-settings-v1
> 上游：`prd-clklog-analytics-workbench-v1.md`、`prd-clklog-analytics-card-save-v1.md`
> 下游：`docs/architecture/clklog-analytics-design-result-settings-v1.md`

---

## 1. 阶段目标与范围

事件 / 漏斗 / 留存结果工具栏用设置齿轮收纳**展示偏好**，避免工具栏被分段按钮挤满。漏斗齿轮：转化率/流失率、方向、颜色、列宽。事件齿轮：图表+表格 / 图表 / 表格，以及折线 / 柱状 / 数值（时长纯数字开关仍在齿轮内）。留存齿轮：曲线+表格 / 曲线 / 表格 / 趋势图。选择随卡片 `_view` 保存。漏斗的「整体/按日/按小时」仍在工具栏（会改查询）。

## 2. 验收标准

- [ ] RS-1：三页结果区有「结果设置」齿轮。漏斗页齿轮在时间维度与漏斗+表格切换左侧；事件 / 留存页工具栏不再并列展示图表/表格分段，那些选项只在齿轮内。
- [ ] RS-2：漏斗齿轮内单选「转化率 / 流失率」，默认转化率。人数列始终在；只显示所选比率列（转化率为百分比，流失率为相对上一步的流失百分比）。漏斗图标签同步该比率。
- [ ] RS-3：保存 / 覆盖卡片写入 `dsl._view.funnel_rate`；打开 `?card=` 还原。无该字段视为转化率。
- [ ] RS-4：看板 `type=funnel` 卡按 `_view.funnel_rate` 显示同一套比率；`chart_type=table` 出表，否则出漏斗图。
- [ ] RS-5：事件齿轮含「展示」与「图表类型」；默认图表+表格、折线。保存写入 `_view.event_layout` / `_view.event_chart`（及已有 `duration_plain`）；打开 `?card=` 还原。图表类型同时写入卡片 `chart_type`（看板仍用该字段）。
- [ ] RS-6：单测覆盖比率列过滤默认转化率、切到流失率；三页齿轮按钮存在；事件 / 留存齿轮内能看到对应展示选项。
- [ ] RS-7：留存齿轮含「展示」（曲线+表格 / 曲线 / 表格 / 趋势图），默认曲线+表格。保存写入 `_view.retention_layout`；打开 `?card=` 还原。

## 3. 非目标

- 不改漏斗 SQL、步骤人数口径。
- 不做看板卡上的现场改设置（改完回分析页保存）。
- 不把漏斗的时间维度（整体/按日/按小时）放进齿轮——该项会重新查询。
- 不改查询 DSL / SQL。

## 4. 体验

齿轮是图标按钮，弹出层挂 `document.body`。选项标签 nowrap。事件 / 留存的图表·表格分段只出现在齿轮内，工具栏留给保存与指标动作。
