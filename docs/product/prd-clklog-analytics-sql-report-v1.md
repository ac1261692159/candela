# PRD：自定义 SQL 分析（SqlReport）

> phase: clklog-analytics-sql-report
> 版本：v1.0（2026-08-27）｜ 上游：`prd-clklog-analytics-v1.md` §4.5 B4（自定义 SQL）
> 下游：`docs/architecture/clklog-analytics-design-sql-report.md`
> AI 交互权威：`docs/product/prd-clklog-ai-analytics-v1.md`
> 本文档是自定义 SQL 分析的**产品层**权威：布局、交互、用户错误提示、保存/历史行为。

---

## 1. 阶段目标与范围（门禁要素①）

解决「数据分析师不知道有哪些数据可用」的核心痛点，交付一个**带元数据辅助的自定义 SQL 分析器**：

- 左侧**数据字典**：展示全部事件、事件属性、用户属性、系统字段，可搜索、可点击插入。
- 中间 **SQL 编辑器**（带元数据驱动的智能补全）。
- 左侧下方**可视化分组 + 筛选**：点选属性生成 `GROUP BY` / `WHERE`（Builder 模式）。
- 底部**查询结果**（表格 + 图表）。
- 右侧 **AI 数据分析**：由 `clklog-ai-analytics-v1` 交付完整 Harness 面板；默认展开、宽度可拖动，AI 可读取 SQL 并提出经用户确认后写回编辑器的修改。
- 执行只读 + 安全限额（时间范围 + 行数 + 超时）。

## 2. 验收标准（门禁要素②）

- [ ] **PRD-SR1**：数据字典可搜索、可点击插入正确类型的属性表达式。
- [ ] **PRD-SR2**：支持两种互斥模式：Builder（点选生成 SQL，编辑器只读）与 SQL（手写 SQL，字典只插入片段，不隐形合并）。
- [ ] **PRD-SR3**：分组支持时间（天/小时/周/月）与属性维度；指标支持事件量/独立用户/数值聚合。
- [ ] **PRD-SR4**：筛选支持属性 + 操作符 + 值，多条件 AND/OR。
- [ ] **PRD-SR5**：结果表格 + 图表 + 行数/耗时/截断提示。
- [ ] **PRD-SR6**：保存报表（含 field_map、chart_config、mode）；历史列表可打开/删除。
- [ ] **PRD-SR7**：错误提示友好（SQL 语法错误、越权表、超时、超限分别给出明确文案）。
- [ ] **PRD-SR8**：SQL 页接入全局 Harness 面板；布局与 SQL 读取/修改验收分别以 AI PRD 的 **AI-1**、**AI-14**、**AI-15** 为准。

## 3. 非目标（门禁要素③）

- 本文档不重复定义 AI 对话、模型、Workspace 和页面桥行为；统一以 `prd-clklog-ai-analytics-v1.md` 为权威。
- 不做留存分析、不做报表定时调度/订阅。
- 不触碰社区版 `clklog` 库（统一查旁路库 `clklog_sa`）。
- 不做跨项目查询（强制当前 `project_name`）。
- 本期不做「专用只读账号隔离」（留 TODO，见架构文档）。

│ · 系统字段      │                               │                │

- 底部通栏结果区。

## 5. 两种互斥模式（核心交互）

| 模式 | 面向 | SSOT | 编辑器行为 | 分组/筛选 |
|------|------|------|-----------|----------|
| **Builder 模式**（默认） | 非技术分析师 | DSL 配置 | **只读展示**生成的 SQL | 面板点选，服务端生成 SQL |
| **SQL 模式** | 懂 SQL 的分析师 | SQL 文本 | **可编辑** | 字典只插入片段，不隐形合并 |

- 顶部「模式切换」切换，切换时提示「将放弃未保存的当前编辑」。
- 两种模式**不混合**：一旦选 SQL 模式，分组/筛选面板隐藏（或只作「插入片段」辅助，不参与执行合并）。

## 6. 数据字典交互

- 四层：事件 / 事件属性 / 用户属性 / 系统字段。
- 全局搜索（按关键字过滤）。
- 类型图标 + 颜色：`string`/`number`/`datetime`/`boolean`/`list`/`object`。
- hover 显示 data_type + sample_value（样例值**默认脱敏**，如手机号显示 `138****0000`）+ 所属事件。
- 点击插入：
  - 事件 → 插入 `WHERE event = 'xxx'`；
  - 属性 → 插入对应类型 JSON 提取表达式（Builder 模式直接进配置，SQL 模式插入文本）。

---

## 7. 分组与筛选（Builder 模式）

### 7.1 分组
- 维度：时间（天/小时/周/月）、事件属性、用户属性、系统字段。
- 指标：事件量 `count()`、独立用户 `uniqExact(distinct_id)`、数值聚合 `sum/avg/min/max`（选数值属性）。
- 多级分组按添加顺序拼接。

### 7.2 筛选
- 属性 + 操作符（`=`/`!=`/`>`/`<`/`in`/`like`/`is null`）+ 值。
- 多条件 AND/OR。
- 筛选值**参数化**（不作为文本拼进 SQL）。

---

## 8. 结果区

- 表格展示 `columns` + `rows`；可切换图表（折线/柱状/表格/数值）。
- 顶部信息条：`行数`、`耗时`、`是否截断`、`扫描行数/字节`。
- 分组结果支持按列排序、导出 CSV（后续）。

---

## 9. 保存与历史

- **保存为报表**：存 `mode` + `sql_text`（或 DSL）+ `field_map`（字段别名映射）+ `chart_config`（图表类型）+ `schema_version`。
- **保存为卡片**：把当前分析作为看板卡片（复用 P3 卡片，存**完整执行规格快照**，避免原报表改动导致卡片语义漂移）。
- **历史**：已保存 SQL 报表列表，可打开 / 删除。

---

## 10. 错误提示（用户可见）

| 场景 | 提示文案 |
|------|---------|
| SQL 语法错误 | 「SQL 语法错误：{具体信息}」 |
| 访问未授权表/库 | 「仅支持查询 clklog_sa 库，不允许访问 {表名}」 |
| 超时 | 「查询超时（30s），请缩小时间范围或简化查询」 |
| 超行数/超扫描 | 「查询超出资源限额，请缩小范围」 |
| 缺时间范围 | 「请先选择时间范围」 |
| 保存失败 | 「保存失败：{原因}」 |

---

## 11. 用户错误路径

- 无看板时点「保存为卡片」→ 提示先创建看板。
- 未执行过查询点「保存」→ 提示先执行。
- 切换模式时未保存 → 二次确认。
