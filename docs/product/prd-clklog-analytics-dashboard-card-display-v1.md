# PRD：看板卡片可点进入 + 位置级展示设置

> phase: clklog-analytics-dashboard-card-display-v1
> 帽子：产品（`docs/product/`）
> 上游：`prd-clklog-analytics-dashboard-studio-v1.md`、`prd-clklog-analytics-explore-charts-v1.md`
> 下游：`docs/architecture/clklog-analytics-design-dashboard-card-display-v1.md`

---

## 1. 阶段目标与范围

看板格子标题一律可点进对应分析页；三点菜单改为「设置 + 从看板移除」。设置里按分析类型选一种展示样式，写在**看板位置**上：同一张库卡在不同看板可以一张折线、一张表格。分析页「图表+表格」布局仍只作用于分析页。

| 模块 | 本次做什么 |
|------|------------|
| 标题 | 事件 / 漏斗 / 留存 / SQL 点进分析页；标签卡打开正文编辑 |
| 面板菜单 | 设置、从看板移除；刷新仍走标题栏 C |
| 展示样式 | 留存三态、事件多图+表、漏斗图/表、SQL 图/表 |
| 持久化 | `DashboardCard.display_json`，不改库卡 `chart_type` |

## 2. 验收标准

- [ ] **CD-1**：事件 / 漏斗 / 留存 / SQL 卡片标题可点，进入对应分析页 `?card=`；标签卡标题打开正文编辑。
- [ ] **CD-2**：三点菜单只有「设置」「从看板移除」；无「刷新数据」「编辑」。标题栏 C 刷新仍在。
- [ ] **CD-3**：留存设置三项：折线图、数值表格、留存表格；看板只渲染选中的一种。数值表为日期+人数+各 N 人数，留存表为日期+各 N 率；未到期为 `-`。
- [ ] **CD-4**：事件可选折线/趋势/柱状/堆积/累计/分布/饼图/数值/表格；漏斗可选漏斗图/表格；SQL 可选折线/趋势/柱状/饼图/数值/表格（配置不兼容则回退表并提示）。
- [ ] **CD-5**：展示写在看板位置；拖拽保存布局不丢展示；覆盖保存库卡不改本看板展示（已设过 display 时）。
- [ ] **CD-6**：缺 display 时回退库卡 `chart_type`（留存 `table`→数值表格，`nth_trend`/`daily_trend`→折线）。
- [ ] **CD-7**：非法 `display` 键或非法 `view` 拒绝保存（400）。棘轮通过。

## 3. 非目标

- 不做看板时间覆盖、改 n_list/指标、预测线、看板筛选。
- 不把漏斗转化口径、事件显示值、SQL 字段绑定搬进面板设置。
- 不在看板顶栏再加卡片级齿轮（整板设置仍用现有齿轮）。
- 看板格子不渲染「图表+表格」并排。
