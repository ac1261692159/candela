## 1. 阶段目标与范围

分析图（事件/漏斗趋势/留存趋势/自定义 SQL）凡有数值 Y 轴的，都要能选**单位**；单位必须**按量级自动换算**，不是只在数字后面贴一个字母。打开已保存的事件 / 漏斗 / 留存 / 自定义 SQL 卡片时立刻显示缓存结果；自定义 SQL 的展示（图表/表格）、图形和字段/单位放在与事件分析相同的顶部齿轮里，不必先点「执行」。折线/柱状等系列只用纯色；点击图例是**独立显示该系列**，不是隐藏它。

| 模块 | 本次做什么 |
|------|------------|
| 单位 | Grafana Unit 调研后取分析场景白名单；默认「数值」；Y 轴刻度、tooltip、指标卡同一套换算 |
| 分析卡片缓存 | 打开已存事件 / 漏斗 / 留存 / SQL 卡片载入 `CardCache`；无缓存时再现场查询。SQL 展示/图形/字段在顶部齿轮 |
| 配色 | 禁止 ECharts decal 棋盘格/斜纹；实测系列纯色实线；预测仍用同色虚线 |
| 图例 | 点击某系列 → 只显示该系列；再点同一系列 → 恢复全部 |

## 2. Grafana 单位调研（取舍）

Grafana `grafana-data` `getCategories()` 大约 20 类、200+ 种 id（Misc / Acceleration / Angle / Area / Computation / Concentration / Currency / Data / Data rate / Date & time / Energy / Flow / Force / Hash rate / Length / Mass / Radiation / Rotation / Temperature / Throughput / Time / Pressure 等）。换算逻辑是按量级选前缀（如 W→kW→MW），不是只拼后缀。

本产品是游戏/运营分析（人数、金额、时长、占比、磁盘），不是工控仪表。全量目录会让「Unit」下拉不可用。

**纳入（自动换算）：**

| id | 显示名 | 源值含义 | 换算 |
|----|--------|----------|------|
| `number` | 数值（默认） | 无量纲计数 | ≥1 万 → 万，≥1 亿 → 亿；更小用千分位 |
| `percent_0_100` | 百分比 (0–100) | 已是百分数 | `12.3%` |
| `ratio_0_1` | 百分比 (0–1) | 比例 | `0.123` → `12.3%` |
| `currency` / `currency_cny` | 人民币 | 元 | `¥` + 万/亿 |
| `currency_usd` | 美元 | 美元 | `$` + K/M/B |
| `duration_sec` | 时长（秒） | 秒 | 秒 / 分钟 / 小时 / 天 |
| `duration_ms` | 时长（毫秒） | 毫秒 | 毫秒 / 秒 / 分钟 |
| `bytes` | 字节 (SI) | 字节 | B / kB / MB / GB / TB（1000） |
| `bytes_iec` | 字节 (IEC) | 字节 | B / KiB / MiB / GiB（1024） |

旧配置 `currency` 视为人民币，行为与 `currency_cny` 相同。

**不纳入：** 加速度、角度、面积、FLOPS、浓度、湿度、坎德拉、十六进制、科学计数、各国法币、比特率、时钟 tick、电能、辐射、质量、温度等。需要时另开 phase，不把 Grafana 下拉整棵搬进来。

## 3. 验收标准

- [ ] **U-1**：折线 / 趋势 / 柱状 / 堆积 / 累计 / 数值卡 的设置里有「单位」，默认「数值」。自定义 SQL 在字段设置里按指标选单位。
- [ ] **U-2**：`12000` + 数值 → 含「万」；`90` + 时长（秒）→ 含「分钟」；`0.123` + 百分比 (0–1) → `12.3%`。Y 轴刻度与 tooltip 同一套。
- [ ] **U-3**：打开已保存的事件 / 漏斗 / 留存 / SQL 卡片，不点「查询/执行」也能看到缓存表/图（标「缓存命中」）。SQL 顶部齿轮里可改展示/单位/绑定；无缓存但有 `chart_config` 时仍能打开设置。无缓存的旧卡保持打开后自动查询。
- [ ] **U-4**：折线/柱状/趋势实测系列为纯色实线，无棋盘格/斜纹/按系列轮换虚线点线。预测系列可以是同色虚线。
- [ ] **U-5**：点击图例「首充金额」只显示该系列；再点一次恢复全部。不是把该系列隐藏。
- [ ] **U-6**：棘轮通过。

## 4. 非目标

- 不引入 Grafana 全部单位目录，不接 `@grafana/data`。
- 不做双 Y 轴；混单位仍警告，tooltip 按各自单位，轴用主指标单位。
- 不改预测开关、日期补全轴、VS/上期对比。
- 不把缓存当实时数；过期仍展示并允许用户再执行。
- 不改漏斗转化率图的点击「从这步起算」（那是漏斗自己的交互）。
- 不改 Harness 插件；不绕过只读 SQL 守卫。
