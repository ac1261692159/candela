### 顶部导航
- 左侧：`ClkLog Admin` 返回社区版首页。

### 左侧菜单
- 埋点管理：元事件、用户属性、虚拟事件、Debug、数据质量。
- 分析：事件分析、漏斗分析、留存分析。
- 报表：看板、自定义 SQL。

```
├──────────────┬────────┬───────────┬─────────────────┤

├──────────────┼────────┼───────────┼──────────┼──────┤
│ product_id   │ 商品ID │ String    │ [物化]   │ [改] │
```

### 交互说明
| 元素 | 行为 |
|------|------|
| 类型下拉 | String / Number / Bool / Datetime / List；自动采样时默认，人工可改 |
| 是否物化 | 点击后异步 ALTER TABLE，完成后显示"已物化" |
| 改 | 修改显示名、类型；类型变更影响 SQL 生成器使用的 JSONExtract* 函数 |
| + 添加属性 | 手工登记属性（用于未上报但已规划的属性） |

## 10. 自定义 SQL 页

路径：`/sa/sql`

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ 自定义 SQL 报表                                               [保存为卡片]  │
├─────────────────────────────────────────────────────────────────────────────┤
│ 名称: [Top10 商品销售额                      ]                              │
├─────────────────────────────────────────────────────────────────────────────┤
│ SQL 编辑器 (只读执行, 超时 30s, 上限 10万行)                                │
│ ┌─────────────────────────────────────────────────────────────────────────┐ │
│ │ SELECT product_id, sum(JSONExtractFloat(properties,'amount')) AS amount │ │
│ │ FROM clklog_sa.sa_events                                                │ │
│ │ WHERE project_name = 'clklogapp'                                        │ │
│ │   AND event = 'Pay'                                                     │ │
│ │ GROUP BY product_id                                                     │ │
│ │ ORDER BY amount DESC                                                    │ │
│ │ LIMIT 10                                                                │ │
│ └─────────────────────────────────────────────────────────────────────────┘ │
│ [执行]  [格式化]                                                            │
├─────────────────────────────────────────────────────────────────────────────┤
│ 字段映射: product_id → 商品ID, amount → 销售额                              │
│ 图表类型: (•) 表格  ( ) 柱状  ( ) 数值卡                                   │
├─────────────────────────────────────────────────────────────────────────────┤
│ 结果预览:                                                                   │
│ 商品ID  │ 销售额                                                            │
├─────────┼───────────────────────────────────────────────────────────────────┤
│ P1001   │ 89,230.50                                                         │
│ P1002   │ 67,120.00                                                         │
│ ...     │ ...                                                               │
└─────────────────────────────────────────────────────────────────────────────┘
```
