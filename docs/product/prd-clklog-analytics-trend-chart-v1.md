# PRD：趋势图（漏斗 / 留存 / 自定义 SQL 接入）

- `phase: clklog-analytics-trend-chart-v1`
- 日期：2026-09-07
- 帽子：产品（`docs/product/`）
- 状态：**已实现**（2026-09-15 回写：漏斗/留存/SQL 三页趋势图与运维面板磁盘预估均基于 `features/visualization/adapters/trend-forecast`）。
- 关联：架构方案 `docs/architecture/clklog-analytics-design-trend-chart-v1.md`；下游消费者 `clklog-analytics-ops-console-v1`（运维面板磁盘预估）

---

## 1. 背景

用户原话：

> 漏斗分析默认是图标的漏斗图，你可以增加显示图选项 漏斗图/趋势图 …… 在选择趋势图，设置菜单改成趋势图的菜单。并使用时间维度，如果有时间维度的菜单，则显示

外加此前需求：

> 留存分析、漏斗分析、自定义 SQL 有无趋势图的图像列表可选？如果没有，增加该图（这个需求优先做，做完了在做运维面板）

**调研结论**：三个分析页面的图形列表里**都没有趋势图**（漏斗：柱状图/表格；留存：留存曲线/表格；自定义 SQL：折线图/柱状图/数值/表格）。同时现有折线图是**类目轴、无预测线**，不能满足磁盘预估/转化率跌破等场景。

故新增**通用趋势图**（独立图表类型，不复用折线图），并在三个分析页面分别接入。

---

## 2. 用户场景

### 2.1 漏斗分析页（重点）

**现状**（截图）：
- 顶部"显示图"三态按钮组：**漏斗+表格 | 漏斗图 | 表格**（默认漏斗+表格）。
- 右侧设置面板（漏斗专用）：转化率/流失率切换、方向（横向/纵向）、表格列宽、默认颜色、转化率分档（80%/50%/50% 以下）。

**变更后**：

1. 顶部"显示图"按钮组增加 **趋势图** 作为第四个选项。
2. **趋势图选项仅在用户选择了「时间维度」时出现**。新增一个"时间维度"选择器：

   | 选项 | 含义 | 可用图形 |
   |---|---|---|
   | 整体（默认） | 单个时间窗口内的总体漏斗 | 漏斗图、表格（与现状一致） |
   | 按日 | 每天一行漏斗结果 | **漏斗图、趋势图、表格** |
   | 按小时 | 每小时一行漏斗结果 | **漏斗图、趋势图、表格** |

3. 选中"趋势图"时：
   - 右侧设置面板**整体替换**为趋势图设置面板（见 §2.4）；
   - 图表区渲染：X 轴 = 时间（日/小时），每条线 = 一个**漏斗步骤**或一个**指标**（人数 / 转化率 / 流失率，由用户在设置面板选择，见 §2.4）。

### 2.2 留存分析页

**现状**：显示图选项为留存曲线、表格。

**变更后**：增加 **趋势图** 作为第三个选项。留存分析天然有时间维度（初始事件 × 回访事件 × 时间窗口），趋势图默认即可用。X 轴默认 = 留存期（Day 0/Day 1/...），Y 轴 = 留存率，每条线 = 一个用户群/初始事件。

### 2.3 自定义 SQL 页

**现状**：图形选项为折线图、柱状图、数值、表格。

**变更后**：增加 **趋势图** 作为第五个选项。X 轴 = 时间列，Y 轴 = 数值列。SQL 卡片保存时可在图表配置中选 `trend`。

### 2.4 趋势图设置面板（统一规格，三个页面共用）

| 项 | 类型 / 默认值 | 说明 |
|---|---|---|
| 显示指标 | 多选（每步人数 / 每步转化率 / 每步流失率；漏斗）/ 单选（指标列；留存与 SQL） | 决定图上有几条线 |
| 预测天数 | 整数输入，默认 7，最大 90 | 0 表示不外推 |
| 阈值线 | 数值输入，可选 | 用于推演「何时跌破 / 达到」 |
| 显示拟合线 | 开关，默认关 | 贯穿全程的回归直线 |
| 显示阈值线 | 开关，默认开（有阈值时） | |

**面板切换规则**：
- 显示图 = 漏斗图 / 留存曲线 / 折线图 / 柱状图 / 数值 / 表格：渲染各自的设置项**（保留现有面板，不动）**。
- 显示图 = 趋势图：渲染**本节**面板。
- 切换显示图时未保存的设置项丢弃（与现有页面行为一致）。

### 2.5 视觉约定（所有页面通用）

- 实际值 = **实线**；预测值 = **虚线**，且鼠标悬停 tooltip 显式标注「预测」。
- 阈值线 = `markLine` 横线；预测线与阈值交汇处标注预计日期。
- 拟合直线（启用时）= 全程细虚线。

## 3. 阶段目标

| 编号 | 目标 |
|---|---|
| G1 | 漏斗 / 留存 / 自定义 SQL 三个页面的图形列表中可选「趋势图」，并按各自数据形态自动适配 |
| G2 | 漏斗分析页新增「时间维度」选择器（整体 / 按日 / 按小时），趋势图仅在有时间维度时出现 |
| G3 | 选中趋势图后，设置面板整体切换为趋势图配置；切换图形时面板能正确来回 |
| G4 | 预测值与实测值在视觉与文案上严格区分，不让用户把推算值当事实 |
| G5 | 为运维面板磁盘预估提供可复用能力（消费方） |

---

## 4. 范围

### 4.1 范围内

1. 通用趋势图图表类型（含回归、外推、阈值推演）——架构文档定义。
2. 三个分析页面接入趋势图选项与各自设置面板。
3. 漏斗分析页新增「时间维度」选择器及对应查询逻辑（按日/按小时生成多行结果）。
4. 卡片保存与还原：`chart_type: 'trend'` 与 `options.trend` 能持久化并复现。

### 4.2 范围外

1. **不**为漏斗「按时间分桶」做超出常规时间窗口的复杂日历（周环比、自然月等，留给后续）。
2. **不**让趋势图参与自动推荐（避免预测值被自动呈现误读）。
3. **不**做季节性 / 指数平滑等复杂模型（线性回归够用）。
4. **不**对旧兼容壳（事件分析、看板 event/retention 卡）做趋势图改造——单独任务。
5. **不**把趋势图开放给管理员以外的运维操作（趋势图本身无权限变化）。
6. **不**修改漏斗的"转化率 / 流失率 / 方向 / 分档"等现有设置项的语义（仅切换面板，不改动原有）。

## 5. 验收标准

| 编号 | 标准 |
|---|---|
| AC1 | 自定义 SQL 页的图形列表新增「趋势图」；选中后图表区渲染趋势图（time 轴 + 实线） |
| AC2 | 留存分析页图形列表新增「趋势图」；默认即可用，不依赖额外选择 |
| AC3 | 漏斗分析页图形列表在「整体」时为漏斗图/表格（与现状一致），在「按日 / 按小时」时新增「趋势图」选项 |
| AC4 | 漏斗分析页「时间维度」选择器三态齐全（整体 / 按日 / 按小时），切换后结果数据行数符合预期（整体 1 行，按日 = 所选区间天数，按小时 = 所选区间小时数） |
| AC5 | 选中趋势图后，设置面板替换为 §2.4 五项；切回漏斗图后设置面板恢复为原漏斗设置 |
| AC6 | 趋势图 X 轴等距：两个时间点在轴上的间距与其时间差成正比 |
| AC7 | 实际值实线、预测值虚线且 tooltip 标注「预测」 |
| AC8 | 配置阈值后显示阈值线，预测与阈值交汇处标注预计日期；无阈值时不显示阈值线 |
| AC9 | 数据点 < 3 时不外推，页面给出「数据点不足，无法预测」提示 |
| AC10 | 卡片保存为 `trend` 类型后，重新打开可完整复现（含 `options.trend`） |
| AC11 | 不影响旧 `chart_type` 配置（折线图/柱状图等）保存与复现 |
| AC12 | 趋势图不参与自动推荐（手动模式可见 / 自动模式下不会被默认选中） |

## 7. 关键产品决策记录

| 决策 | 选择 | 理由 |
|---|---|---|
| D1 | 漏斗「整体」模式不显示趋势图选项 | 整体模式只有 1 行结果，无法成趋势；避免出现 1 点的"假趋势"误导 |
| D2 | 趋势图不参与自动推荐 | 与架构方案 D4 一致；预测值属推断，应由用户主动选择 |
| D3 | 漏斗按时间分桶默认粒度按"按日"，小时仅在区间 ≤ 7 天时启用 | 7 天 × 24 小时 = 168 行仍可读；超过则回退到"按日"，避免点数过多影响渲染与拟合 |
| D4 | 漏斗趋势图默认 Y 轴指标 = "每步人数"，转化率 / 流失率需手动加 | 人数曲线最直观；转化率跌破需主动配置 |
| D5 | 趋势图设置面板不沿用漏斗/留存的现有面板控件，必须独立 | 设置项语义不同（漏斗分档 vs 趋势阈值）；混用会歧义 |
