# PRD：事件分析图表字段绑定与显示优化（v1）

- phase: `clklog-analytics-event-chart-binding-v1`
- 帽子：产品（`docs/product/`）
- 对应实现方案：`docs/architecture/clklog-analytics-design-event-chart-binding-v1.md`
- 对标能力：自定义 SQL 结果区的「展示 → 字段」面板（`ChartConfigV1`）
- 状态：待评审

---

## 1. 背景：今天的问题

事件分析结果区的图表设置只有五项：展示方式（图表+表格 / 图表 / 表格）、图表类型（8 种）、统计值、Y 轴单位、时长显示。而「数据列 → 图表元素」的映射是**写死的**：

| 图表元素 | 今天的取值 | 代码位置 |
|---|---|---|
| X 轴 | 第一个分组列 `g_0` | `apps/analytics-web/src/features/explore-charts/explore-chart-option.ts:102` |
| 系列 | 每个指标列各一条 | 同上 `:105-108` |
| 第二个及以后的分组列 `g_1…` | **完全不上图** | 同上（只取 `groups[0]`） |
| Y 轴 | 全部指标共用一条，单位全局一个 | `apps/analytics-web/src/features/query/EventViewSettings.tsx:97-112` |

这三点在真实数据上会同时出问题。以实际查询为例：按 `channel_name`（渠道 URL）分组，三个指标的首位渠道取值是——

| 指标 | 值 |
|---|---|
| 消耗总量 | 18,641 |
| 消耗用户数 | 98 |
| 消耗均值_人均 | 190.214 |

单条 Y 轴自动取到 0–21,000，于是「消耗用户数」与「消耗均值_人均」被压成贴着基线的直线，渠道之间的差异完全读不出来——而这两条恰恰是业务最关心的转化质量指标。同一张图上，X 轴是长 URL 维度，标签互相重叠，第一个标签还被左边缘裁掉了一半。

自定义 SQL 的结果区已经解决了同类问题：「展示」面板可以指定**时间轴 / 系列 / 指标 / 单位 / 排序指标 / TopN**，配置以 `ChartConfigV1` 持久化到卡片。这套能力没有用到事件分析上。

## 2. 目标用户与场景

**用户**：日常看渠道、落地页转化质量的运营与数据分析同学。

**场景 A — 量级差异**：按渠道同时看「消耗总量」和「消耗用户数」。总量 1.8 万而用户数只有两位数，单轴下图二永远贴在 0 线上。
→ 需要 R5（双 Y 轴）+ R7（每指标单位）。

**场景 B — 双维度**：按「渠道 × 城市」看转化率。今天第二个分组列直接不上图，用户只能回到表格里自己找。
→ 需要 R2（X 轴可选）+ R3（拆分系列）。

**场景 C — 长维度名**：按落地页 URL 分组，标签重叠、首尾被裁切，看不清是哪一页。
→ 需要 R6（长标签可读）。

## 3. 需求条目

### R1 列角色可见、可改

结果区「展示」面板新增「字段」区。每列出其角色（时间 / 维度 / 指标），用户可把某列改成「忽略」——被忽略的列既不进图也不进表。

**验收**：面板列出的列与本次结果列一一对应；把一列设为忽略后，图与表都不再出现它；角色与忽略状态保存卡片后复现。

### R2 X 轴可选

「字段」区提供 **X 轴**下拉，候选 = 本次结果里角色为「时间」或「维度」的列；缺省选中第一个时间列，没有时间列时选中第一个维度列。

**验收**：可把一个维度列选为 X 轴；换 X 轴后**不产生新的后端查询**；表格数据不变，只有图重画。

### R3 拆分系列

「字段」区提供 **拆分系列**下拉，候选 = 除 X 轴外的「时间 / 维度」列，含「不拆分」。选中后按该列的取值把一个指标画成多条线。

**验收**：系列数 = 该维度取值数（按 R6 上限截断）；同一 X 取值、同一拆分取值的多行按**求和**合并，并在界面上给出说明。

### R4 指标可选

「字段」区提供 **指标**多选，候选 = 角色为「指标」的列，缺省全选。

**验收**：取消勾选某指标后该指标不上图（表格仍显示）；勾选顺序决定系列顺序。

### R5 双 Y 轴

每个指标可单独指定走**左轴**或**右轴**，左右轴各自按所属指标的单位格式化刻度。同时，当指标之间的量级差异达到阈值时，界面出现一条**建议**（指出哪几个指标适合拆到右轴 + 一键应用）；用户不点，图表不变。

**验收**：
- 至少一个指标设为右轴后，图上出现左右两条刻度轴；
- 全部指标都在左轴时不出现第二条轴；
- 指标最大值的比值 ≥ 50 倍时出现建议条，点「应用」后配置写入并可保存；
- 建议条出现本身不改变任何已保存状态。

### R6 长标签可读

X 轴标签按分类数与标签长度自动选择直排 / 旋转 / 截断，任何情况下不被容器裁切；鼠标悬停显示完整的标签原文。

**验收**：`channel_name` 这类长 URL 维度下标签不重叠、不出界；悬停能读到完整 URL。

### R7 每指标单位

单位从「全局一个」改为「每个指标一个」。缺省值的取法：**卡片上显式设过「Y 轴单位」（非数值）时整张图沿用用户的选择**；
否则按指标列自身类型推导（比率 → 百分比 / 0–1，时长 → 秒，其余 → 数值）。

**验收**：
- 给「消耗均值_人均」设百分比不影响「消耗总量」的刻度格式；
- tooltip 按各系列自己的单位显示；
- 「单位」下拉仍可一次改掉全部已绑定指标（它是「整张图的缺省」），想只改一个走「字段 → 指标单位」。

### R8 配置持久化与复现

上述配置随卡片保存，重新打开（分析页 / 看板）能复现。

**验收**：分析页保存卡片 → 刷新 → 重新打开，X 轴 / 拆分系列 / 指标 / 轴归属 / 单位全部复现；看板里的同一张卡片也复现。

### R9 与自定义 SQL 共用一份配置契约

事件分析与自定义 SQL 使用**同一个**配置对象（`ChartConfigV1`）与**同一套**服务端校验，不新增第二套配置格式。

**验收**：事件卡与 SQL 卡的 `dsl.chart_config` 通过同一份校验器；非法配置被服务端拒绝。

### R10 旧卡片零行为变更

本次改造前保存的卡片，打开后的图表与改造前一致（除非用户主动改绑定）。

**验收**：取一张改造前保存的多指标事件卡，改造后打开，图型、系列集合、轴数量与边距与改造前一致。

**唯一允许的差异**：卡片上「Y 轴单位」是缺省的「数值」、且第一个指标是比率列或时长列时，轴与 tooltip 会改用该指标自身的单位格式（百分比 / 秒）。这正是 R7 要修的问题。

## 4. 交互设计

「展示」齿轮弹层（`analysis:view.display`）在现有分区之后追加一个「字段」区：

```
展示
  [图表+表格] [图表] [表格]
图表类型
  [折线] [趋势] [柱状] [堆积] [累计] [分布] [饼图] [数值]
统计值 / 单位 / 时长显示        ← 现状，单位收窄为「未单独指定时的缺省值」
─────────────────────────────
字段
  X 轴        [ channel_name ▾ ]        候选：时间 / 维度列
  拆分系列     [ 不拆分 ▾ ]              候选：除 X 轴外的时间 / 维度列
  指标         [消耗总量 ×] [消耗用户数 ×] [消耗均值_人均 ×]
  列角色
     m_0  消耗总量        指标      [轴: 左 ▾] [单位: 数值 ▾]
     m_1  消耗用户数       指标      [轴: 右 ▾] [单位: 数值 ▾]
     m_2  消耗均值_人均     指标      [轴: 右 ▾] [单位: 数值 ▾]
     g_0  channel_name   维度      [角色: 维度 ▾]
─────────────────────────────
⚠ 指标量级差异 190×，建议把「消耗用户数、消耗均值_人均」拆到右轴   [应用]
```

要点：

- 「轴」与「单位」两个下拉**改完立即生效**（与自定义 SQL 的字段面板一致），其余项点「应用配置」后生效。
- 建议条只在量级差异 ≥ 50 倍且当前是单轴时出现；点「应用」才会写入配置。
- 拆分系列造成的行合并会以一行灰色说明展示（「同一 X 值已按求和合并」），不弹窗打断。

---

## 5. 非目标

1. **不改查询**。绑定是纯展示层：换 X 轴、拆分系列、指标都不触发后端重查。
2. **排序指标与 TopN 只在已返回结果集内生效**，不重取 TopN。结果集的抽样仍由左侧查询配置（分组 + TopN + 指标顺序）决定。
3. **不把事件分析迁移到 SQL 的图表管线**。两套 option builder 短期并存，收敛单独排期。
4. **不改漏斗与留存**。留存有自己的「第 N 日趋势」形态，漏斗有自己的图形。
5. **不新增图表类型**。事件侧仍是 8 种；不复用 SQL 侧的「条形 / 环形」。
6. **不改自定义 SQL 的任何现有行为**。SQL 卡不出现新字段，既有配置照旧。
7. **不做分类缩放（dataZoom）**。分类数过多时的滚动缩放留到下一版。

## 6. 术语

| 术语 | 含义 |
|---|---|
| 列角色 | 结果列的语义分类：时间 / 维度 / 指标 / 忽略 |
| 绑定 | 把结果列指派到图表元素（X 轴 / 拆分系列 / 指标）的配置 |
| 拆分系列 | 按某个维度列的取值把一条线拆成多条线（等价于透视） |
| 量级差异 | 多指标各自最大绝对值之间的比值 |
| 轴归属 | 某指标画在左轴还是右轴 |
