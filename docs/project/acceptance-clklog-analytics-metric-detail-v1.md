## 1. 结论

**通过**（含验收中实测发现并修复的**两处后端问题**）。指标现在可以查看完整口径、就地编辑（含口径），删除保留；编辑保持 `metric_id` 不变，不影响分析与告警引用。

先回答用户的问题：**是的，此前前端只能删**。核查后确认——后端 `GET/PUT /sa/api/meta/metrics/:id`（权限 `metric.view` / `metric.edit_own`）**早就存在**，缺的只是前端接线：列表只有「删除」一个动作，导致用户只能「删了重建」，而重建会换 `metric_id`，把已有告警绑定与分析引用悄悄弄断。本次为纯前端补齐 + 两处后端健壮性修复（下表），**未新增 API 契约**。
