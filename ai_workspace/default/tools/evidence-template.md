# 分析证据记录模板

迁自 thinkingdata 的来源/条件/复现记录方法。只保存最小必要的脱敏聚合；历史结果、合成测试与现网查询分开。文件建议放 `files/notes/日期-主题.md`。

## 可复制结构

```text
主题：
记录时间（含时区）：
当前项目（来自平台）：
状态：pending / verified / conflict / blocked
数据类别：live_query / page_result / historical_reference / synthetic_fixture
用户问题与已确认口径：
日期范围、时区、观察窗口成熟情况：
事件与属性：
分析主体、分子、分母、单位：
完整 DSL 或 SQL 文件路径：
来源工具、查询时间、query_id（如有）：
聚合结果、总行数、返回行数、是否裁剪：
页面状态：未填表 / 已填表 / 页面已计算 / 仅工具计算
交叉核验：同条件结果、差异、原因
历史候选的源文件与 SHA-256（如使用）：
本次核验结论与仍缺条件：
错误类别与已尝试修正（如有）：
复现步骤：
```

不得填写登录 token、签名 URL、数据库连接串、供应商密钥、明细用户行。无法拿到 query_id 时写“工具未提供”，不能伪造。没有经过现网核验的候选资料保持 pending，不因文件迁移成功标成 verified。
